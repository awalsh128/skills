# Personal tooling or other README

Applies to dotfiles, scripts, sites and prototypes meant mainly for the owner. Exemplar: https://github.com/awalsh128/aw-home

## Shape

- Title and a one-line description. No badge row, no emoji bullets, no sponsor badge unless the repo is meant for other people.
- Headings named for what the reader is trying to do, in order: New machine, Day to day, Local preview, Deployment.
- Short sections, commands in fenced blocks, tables only for real tabular content (e.g. what is synced).
- Logo and emoji only if the repo already has them.

## Notes

- Keep it short. If a section would only restate the code, leave it out.
- No bare title stub for a repo anyone else will open: at least what it is and how to run it.
